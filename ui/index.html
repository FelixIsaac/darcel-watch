SF Service Guide Watch

Keeping San Francisco's safety-net directory true.

What this is: an agent that re-checks every listing in the SF Service Guide — the directory unhoused San Franciscans use to find food, shelter, clinics and legal aid — against each organisation's own live website, and says so when the stored details are wrong. Who uses it: a ShelterTech volunteer, who reviews each finding and approves it by hand. The person it helps is someone looking for a meal tonight, who never sees this page. Nothing here is ever written to the live directory automatically.

Source: sfserviceguide.org (nonprofit ShelterTech) — 1,759 organisations and 7,577 services, counted from their live API. ShelterTech report 16,000+ monthly users.

The state of the directory

The directory is actively maintained — 808 of 813 approved listings were updated in the last 90 days. What is missing is provenance: updated_at records that something changed, not that anyone confirmed it against reality. The field that would carry that, verified_at, stopped being written around 2022; certified_at is still used but rarely. So nobody — including ShelterTech — can tell a freshly confirmed listing from a stale one. That is the gap this tool fills.
